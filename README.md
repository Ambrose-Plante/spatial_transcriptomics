# Spatial transcriptomics research

Exploratory work on histology-informed representation learning and spatial gene-expression analysis.

## Projects

- [ST_HE_pretraining_idea_1](ST_HE_pretraining_idea_1/) — Representation learning with histology imagery as a pretraining signal.
- [ST_HE_pretraining_idea_2_simple](ST_HE_pretraining_idea_2_simple/) — Paired histology/spatial-transcriptomics representation modeling.

## Ding Lab scripts

Each research file is organized into its own folder with a project README:

- [Seurat_to_python](Ding_Lab_scripts/Seurat_to_python/) — Seurat/Xenium data preparation.
- [fast_morph_scripts](Ding_Lab_scripts/fast_morph_scripts/) — Spatial grid and morphology-based proximity helpers.
- [filter_algorithm_morph](Ding_Lab_scripts/filter_algorithm_morph/) — Exploratory morphological filtering notebook.
- [morphcia](Ding_Lab_scripts/morphcia/) — Spatial neighborhood gene-expression analysis.
- [run_morphcia_with_wait](Ding_Lab_scripts/run_morphcia_with_wait/) — Concurrent post-processing job launcher.

These scripts are historical research code and may require private input datasets, environment-specific paths, and additional dependencies. See each folder's README before running.
